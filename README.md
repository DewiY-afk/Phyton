# Proyek Prediksi Kelulusan Mahasiswa 🎓

Proyek ini menggunakan **Decision Tree Classifier** untuk memprediksi apakah mahasiswa akan **lulus tepat waktu**, berdasarkan fitur:
- Umur
- IPK
- Jurusan

## 📁 File
- `data.csv` — Dataset mahasiswa
- `decision_tree.ipynb` — Notebook model machine learning
- `model.pkl` — Model terlatih

## 🔍 Hasil
Model mencapai akurasi sekitar **90%** pada data latih.

## 📊 Visualisasi
Terdapat grafik IPK, dan pohon keputusan yang divisualisasikan dengan `sklearn.tree`.

## 🚀 Cara Menjalankan
1. Buka file `decision_tree.ipynb` di Jupyter/Colab
2. Jalankan semua sel
3. Prediksi bisa dilakukan untuk data baru

## ✅ Dependensi
- Python 3
- pandas, scikit-learn, matplotlib, seaborn
